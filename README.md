# Expense Tracker CLI 🧾💰

A simple **Command Line Interface (CLI) Expense Tracker** built using **Python**.  
This application allows users to record, view, and manage their daily expenses using an interactive, menu-driven terminal interface.

---

## 📌 Features

- Add expenses with:
  - Amount
  - Category
  - Description
- View all expenses in a formatted table
- Calculate total expenses
- Menu-driven CLI interface
- Uses Object-Oriented Programming (OOP)

---

## 🛠️ Tech Stack

- Python 3
- Object-Oriented Programming (OOP)
- CLI-based interaction
- `match-case` (Python 3.10+)
